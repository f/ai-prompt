A production-style tutorial post showing how AI Prompt blocks can document a vibecoding workflow for a simple Tip Card Gutenberg block.

- Local Playground URL used while authoring: http://127.0.0.1:9400/2026/05/11/how-to-vibecode-a-gutenberg-block/
